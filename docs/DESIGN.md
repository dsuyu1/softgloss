# Reading panel design, 0.8.0

The user supplied [Pomodoro App – Chrome Extension, Community](https://www.figma.com/design/pDJAu3ApD2M1YEq0s0xy5l/Pomodoro-App---Chrome-Extension--Community-?node-id=1-713) as inspiration, explicitly requesting a dictionary extension rather than a Pomodoro app. Inspected the Default frame 1:865 via Figma design context and screenshot. Adapted its compact header, 16px spacing, white/gray surfaces and coral primary action. No timer, logo, illustration, font or SVG asset was copied. SoftGloss retains its own identity and system fonts. The action coral is darkened to #b7482b for readable white text.

Dictionary cards group analyses of the same source entry, preserve separate homonyms, expose the first meaning immediately and place all senses behind a disclosure. Settings are collapsed. Grammar uses amber, nouns blue, predicates purple and constructions teal, always with text labels. Vocabulary status is a separate labeled control; existing page highlights use gray unknown, amber seen and green known. Color is supplementary. Keyboard focus outlines, explicit button names and the closed shadow boundary remain. Width adapts to a 360px reading viewport.

For recognized patterns, compatible predicate forms and construction-specific 수/있다 entries are shown first. Other homonyms remain available in a disclosure with a standalone lookup button. This avoids presenting unrelated dictionary senses as the phrase meaning.

On-page highlights set both the pale background and a dark foreground, preserving text contrast on dark host pages as well as white pages. This does not change unhighlighted host text.
