# Official default study curriculum (0.10.0)

Publisher: National Institute of Korean Language (국립국어원). Work: 2017 International Standard Curriculum for Korean Language Education application study (stage 4), vocabulary/grammar grade appendix, revised 2020-11-17. Research lead 김중섭 and team. Downloaded 2026-10-25 directly from the [official report page](https://www.korean.go.kr/front/reportData/reportDataView.do?mn_id=45&report_seq=932). That page explicitly displays KOGL Type 1 (attribution); Type 1 permits commercial/noncommercial reuse and adaptations with attribution. We use that grant, not the separate AI-training terms. No endorsement is implied.

The source contains 10,635 vocabulary rows and 336 grammar rows. The extract retains vocabulary row ID, source grade, headword and POS, plus grammar IDs, grades, category, representative/related forms and meaning labels. Vocabulary examples and other spreadsheet material are omitted. Source homonym numbers are removed for lemma matching; slash-separated alternate/POS headwords are split; duplicates retain the minimum source grade. This yields 9,719 Hangul-only lemmas. Non-Hangul/multiword omissions and exact counts are enumerated in the generated manifest. Full retained rows are pinned in the compressed snapshot. Raw XLSX and snapshot hashes are in data/curriculum-lock.json.

These are official Korean curriculum grades, not asserted official TOPIK word assignments. We checked the TOPIK administrator homepage but did not obtain a directly downloadable, clearly licensed current six-grade exam syllabus there. We therefore do not use unofficial mirrors or claim the NIKL curriculum is an exhaustive TOPIK syllabus.

Rebuild: `python3 scripts/import-curriculum.py`. Uses standard-library JSON/gzip; original XLSX inspection used openpyxl once. CI rebuilds offline from the pinned selected-field snapshot and rejects generated-file drift. Hash checks cover every generated study shard. Runtime has no network dependency.

Scanning: exact source lemmas and dictionary-backed inflections qualify by vocabulary grade. Grammar catalog entries generate possible particle, ending and expression matches only where supported dictionary morphology/particles and adjacent components fit. Noun suffix coincidence is rejected. Single token endings highlight their token; multiword expressions highlight their range. Unsupported inflections are not guaranteed, and homonym/meaning disambiguation remains incomplete. Sentence context is punctuation based and bounded as documented in VALIDATION.md; grammar expressions currently match within each scanned text node, while sentence context can cross inline elements.

Custom imports are additive, preserve bundled data, and use the lower grade on duplicates. Removing custom lists does not remove the source pack. Imports are local; old learning backups remain compatible and do not include custom study lists.
