# Data provenance and import gate
Current data.js contains 52 original brief starter glosses and explicitly listed forms, authored for this alpha. They require Korean-language review before public release. No third-party dictionary, parser, corpus, audio or competitor dataset has been copied or bundled.

Candidate research, not approved dependencies:
- NIKL Korean Basic Dictionary: https://krdict.korean.go.kr/eng/mainAction
- Wiktionary Korean data: https://en.wiktionary.org/wiki/Wiktionary:Copyrights
- Kengdic upstream: https://github.com/garfieldnate/kengdic

Before importing any source, verify its actual upstream license and rights for the specific snapshot and fields; do not infer rights from other apps' attribution pages. Record the source URL, snapshot/checksum, license text, required attribution, modification notices, redistribution/commercial obligations, and separate audio/example restrictions. Retain provenance per entry. Review compatibility before choosing the project's public code license; no open-source license has been selected yet.

Parser acceptance: deterministic local runtime; documented dependency/data licenses; bounded memory and startup time; stable lemma identifiers; ambiguity preserved; offline reproducible build; no remote executable code.
