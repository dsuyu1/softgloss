# Alpha privacy notice
SoftGloss has no network code, accounts, analytics or AI calls. When enabled by toolbar click or keyboard shortcut, it reads text in the current page for local Korean lookup and vocabulary highlighting. It skips editable fields. The user grants temporary activeTab access, scripting injects the packaged code, and storage retains local learning data.

Saved sentence cards contain the selected word, gloss, nearby text (up to 2,000 characters), and page origin/path without query or fragment. Paths can themselves contain sensitive information; only save content you want to keep. Nothing is uploaded. JSON backups and TSV exports contain your saved material; handle them as personal data.

Delete individual cards in My library. To reset vocabulary and cards, use Delete all learning data in My library and confirm. Display preferences are retained. You can also remove the extension. Uninstalling removes extension-local data; export first if you want to keep it. No cross-device synchronization is implemented.

Dictionary data and scripts are packaged with the extension. Source/credit links open external websites only when you click them; lookup itself makes no outgoing request. New dictionary-derived cards also keep the dictionary entry ID, source URL and license so attribution survives backup/export.
