# Alpha privacy notice
Malnaru Read has no accounts or analytics. Core reading works offline; the optional, explicitly configured speech pilot sends practice content for synthesis/assessment as described below. When enabled manually or through optional automatic mode, it reads text in the current page for local Korean lookup and vocabulary highlighting. It skips editable fields. The user grants temporary activeTab access, scripting injects the packaged code, and storage retains local learning data.

Saved sentence cards contain the selected word, gloss, nearby text (up to 2,000 characters), and page origin/path without query or fragment. Paths can themselves contain sensitive information; only save content you want to keep. Saving cards does not upload them. JSON backups and TSV exports contain your saved material; handle them as personal data.

Delete individual cards in My library. To reset vocabulary, sentence cards, review cards and saved lesson drafts, use Delete all learning data in My library and confirm. Display preferences are retained. You can also remove the extension. Uninstalling removes extension-local data; export first if you want to keep it. No cross-device synchronization is implemented.

Dictionary data and scripts are packaged with the extension. Source/credit links open external websites only when you click them; lookup itself makes no outgoing request. New dictionary-derived cards also keep the dictionary entry ID, source URL and license so attribution survives backup/export.

Pronunciation (optional): **Listen** plays a clip packaged with the extension for curriculum words. Otherwise it uses an offline Korean voice installed on your device through Chrome's text-to-speech API. Voices Chrome marks as remote (cloud) are never used, so the word is not sent anywhere. The clips are machine-generated; see the packaged credits.

Automatic website mode (optional): enabling it requests HTTP/HTTPS host access from Chrome and registers a small packaged listener on permitted pages. It inspects Korean text under the pointer or in a selection, then loads the local dictionary on first interaction. Nothing is uploaded. Disabling automatic mode unregisters the listener for future pages and stops existing auto-loaded panels; listeners already present cannot load the dictionary while the setting is off. Manual activation still works without persistent website permission. Chrome permission revocation switches automatic mode off.

Review cards store the chosen dictionary entry/meaning, optional nearby sentence and origin/path, FSRS memory state and due date, and up to 1,000 recent rating timestamps per card. They remain in chrome.storage.local. JSON backups contain this schedule/history; Anki TSV exports contain card content without scheduling history. Cards can be suspended, resumed or removed in My library. Enabling a page also scans accessible embedded article documents; frame-origin access remains subject to Chrome’s permissions.

Review undo keeps one previous card snapshot on this device to reverse the latest rating. Another rating replaces it; restore and deletion clear it. This temporary undo snapshot is excluded from exported backups.


## Optional speech pilot (0.20.0)
Core lookup, scanning and reviews remain local. Connected sentence synthesis sends the displayed practice sentence through the configured gateway to Azure Speech if no installed local Korean voice is available. Configure this explicitly in Settings. Pronunciation assessment sends the recording plus reference sentence only after checking the upload checkbox and clicking Grade recording. Recordings are converted to mono PCM in memory. Gateway access tokens live in Chrome session storage, separate from backups; Azure credentials remain server-side. Disconnect clears the access token. The pilot gateway writes no audio/transcript logs and stores no recordings; Azure processes submitted audio/text under its service terms. The operator must review Azure region, processing/retention terms and contractual requirements before wider launch. Cancelling cannot recall a request already received by the provider. Grading consumes provider usage; the gateway's per-process ceiling is a private pilot control, not production billing. No browsing history is sent by speech practice.
