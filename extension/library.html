Using Malnaru Read

Enable on a regular webpage using the toolbar. Hover or select a Korean word, or press Alt+Shift+K to focus dictionary search. You can change the shortcut at chrome://extensions/shortcuts.

Close hides the panel; Disable on this page stops lookups and highlighting until you enable again. Highlight vocabulary is a preference shared across tabs. Word status is always available as text here and in lookup results.

Dynamic pages refresh automatically. Highlighting is bounded to the first 10,000 text nodes and 500,000 scanned characters (10,000 per node). Internal browser pages, extension/store pages, PDFs, and canvas text are unsupported. Embedded articles work where Chrome grants access to their website. Other-origin frames require optional website access.
